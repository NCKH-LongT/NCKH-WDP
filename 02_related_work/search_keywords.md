# Academic Search Keywords Matrix

Bảng dưới đây liệt kê các từ khóa tìm kiếm học thuật (Search Queries) và mô-đun ứng dụng tương ứng (Target Module) được rút ra từ 10 bài báo nghiên cứu nền tảng để phát triển dự án **SEAL Hackathon Management System**:

| STT | Từ khóa tìm kiếm học thuật (Search Queries)                                                        | Mô-đun ứng dụng tương ứng (Target Module)                                                                                        |
| :-- | :------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------- |
| 01  | `"Retrieval-Augmented Generation"` `"context-aware code review"` `"repository context extraction"` | **AI-Core**: Kỹ thuật RAG truy xuất và đọc hiểu ngữ cảnh kho lưu trữ mã nguồn (GitHub).                                          |
| 02  | `"LLM-based autograding"` `"automated code review"` `"software engineering education"`             | **Evaluation-Engine**: Động cơ AI phân tích mã nguồn và đề xuất điểm số sơ bộ cho đội thi.                                       |
| 03  | `"inter-rater reliability"` `"Krippendorff's alpha"` `"human-AI consensus"`                        | **Research-Metric**: Đo lường tính nhất quán, độ tin cậy liên đánh giá viên giữa hội đồng giám khảo và AI.                       |
| 04  | `"Zero-shot-CoT"` `"constructive feedback generation"` `"LLM-as-a-Judge"` `"G-Eval"`               | **Feedback-Module**: Kỹ thuật Prompt tối ưu hóa để AI tự động tạo nhận xét mang tính xây dựng theo bộ tiêu chí (Rubric).         |
| 05  | `"human-in-the-loop"` `"LLM hallucination mitigation"` `"grading manual override"`                 | **System-Architecture**: Cơ chế kiểm soát ảo giác, đảm bảo quyền quyết định cuối cùng và ghi đè điểm số của giám khảo con người. |
| 06  | `"code comprehension"` `"repository summarization"` `"software architecture extraction"`           | **UI/UX-Dashboard**: Module tự động tóm tắt kiến trúc và chức năng dự án, giúp giám khảo nắm bắt nhanh nội dung bài thi.         |
| 07  | `"static code analysis"` `"production-ready code benchmark"` `"code quality metrics"`              | **Code-Quality**: Tiêu chuẩn đánh giá mã nguồn, clean code và khả năng triển khai thực tế của sản phẩm Hackathon.                |
